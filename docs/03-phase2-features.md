# Phase 2：核心功能增强（中期 · 2-4 周）

> **目标**：围绕"记账"核心场景，补齐用户真正需要的功能闭环，提升留存率。

---

## 2.1 预算管理

| 优先级 | 任务 | 说明 |
|--------|------|------|
| P0 | 后端预算 CRUD | `Budget` 实体 + Repository + Service + Controller |
| P0 | 每月预算设置 | 按分类设置月度预算金额 |
| P1 | 预算进度仪表盘 | 首页/统计页显示各分类预算使用进度条 |
| P1 | 预算超额提醒 | 分类消费超过阈值时弹窗/Toast 提醒 |
| P2 | 智能预算建议 | 基于历史消费数据自动推荐预算额度 |

**数据模型新增：**
```sql
CREATE TABLE budgets (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL,
    category_id BIGINT NOT NULL,
    month VARCHAR(7) NOT NULL,        -- "2026-04"
    amount DECIMAL(10, 2) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_category_month (user_id, category_id, month)
);
```

## 2.5 AI 功能深化

| 优先级 | 任务 | 说明 |
|--------|------|------|
| P0 | 语音输入 | 利用 Web Speech API (SpeechRecognition)，语音转文字后交给 AI 解析 |
| P1 | 多轮对话 | AI 可追问模糊信息 ("你这杯咖啡是大杯还是中杯？") |
| P1 | 智能分类建议 | 基于历史记录，为新记录自动推荐最可能的分类 |
| P2 | 月度消费总结 | AI 自动生成月度消费分析报告 (自然语言) |

**语音输入实现路径：**
```
用户语音 → Web Speech API → 语音文本 → 阿里云 Qwen API → 结构化数据 → 记账
```
