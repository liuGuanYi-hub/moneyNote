# Phase 3：进阶功能与智能化（长期 · 1-2 个月）

> **目标**：从"记账工具"进化到"个人财务管家"，提供智能分析和财务规划能力。

---

## 3.1 AI 深度集成

### 智能财务分析
- **异常交易检测**：AI 识别异常大额/频繁交易并提醒
- **消费模式识别**：自动发现订阅服务、周期性消费
- **财务健康评分**：基于收入/支出/储蓄/负债等维度综合评分
- **个性化省钱建议**：AI 分析消费结构，给出可执行优化建议

### AI Chat 助手
- 记账 App 内嵌 AI 对话窗口
- 支持自然语言查询：_"我这个月花了多少钱在吃饭上？"_
- 上下文理解：_"比上个月多了还是少了？"_

```
用户: "我这个月餐饮花了多少？"
AI  : "截至4月25日，本月餐饮消费共 ¥1,258.00"
用户: "比上个月多吗？"
AI  : "是的，比3月（¥980.00）增加了 28.4%，主要增加在..."
```

## 3.2 投资理财跟踪

| 任务 | 说明 |
|------|------|
| 资产账户 | 现金、银行卡、余额宝、基金、股票等各类型账户 |
| 手动资产记录 | 定期记录各账户余额，追踪净值变化 |
| 投资收益率计算 | XIRR 年化收益率计算 |
| 净值趋势图 | 总资产/总负债/净资产随时间变化曲线 |
| 资产负债报表 | 资产负债表 + 财务比率分析 |

## 3.3 财务规划

| 任务 | 说明 |
|------|------|
| 储蓄目标 | 设定目标 (如"年底存 5 万")，跟踪进度 |
| 分期/贷款计算器 | 等额本息/等额本金计算 |
| 预算推荐引擎 | 基于个人消费习惯 + 行业标准推荐预算分配 |
| 现金流预测 | 基于历史数据和定期账单预测未来现金流 |
